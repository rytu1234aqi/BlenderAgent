# 前端来源与许可证说明

## 上游来源

本工作台的界面方向、React 三栏布局和 Three.js 查看器参考并改造自：

- 仓库：https://github.com/Iroha021/blender-agent-
- 审阅提交：`a8b78990d661b62f7f5941a6a16528f0e1f63ed1`

保留或重写的主要部分包括 React 三栏拖拽布局、GLB 加载、OrbitControls、线框、网格统计和单文件 Vite 构建思路。资产取景已改为排除明确命名的展示辅助对象，按真实可编辑资产计算包围盒。

## 未接入的上游能力

本集成没有引入原仓库的 DeepSeek 自由工具循环、Blender MCP、`execute_python`、任意文件新建／删除接口或反射任意 Origin 的 CORS 配置。正式编辑链路只调用 BlendGuard 现有受控 CLI。

当前新增的 DeepSeek 支持是 BlendGuard 自己实现的官方 API 结构化规划适配器：模型只返回编辑意图，不接收工具，也不能执行 Python。它与上游仓库的自由工具循环无关。
